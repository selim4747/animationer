Kullanım Rehberi & Özellikler

1. Hibrit Yükleme: Bilgisayarınızdan istediğiniz .glb / .gltf 3D modelini veya .png / .jpg / .webp 2D harita ve zemin görselini pencereye sürükleyip bırakabilirsiniz.

2. 2D Görsel Yönelimi: Yüklediğiniz 2D zemin veya plan görsellerini paneldeki butonla tek tıkla Zemin (Yatay - XZ) veya Arka Plan (Dikey - XY) konumuna getirebilirsiniz.

3. Kamera Açısı Sabitleme: Fare ile sahnede serbestçe gezin (Sol tık: Döndür, Sağ tık: Kaydır, Tekerlek: Yakınlaş). İstediğiniz açıya geldiğinizde "Mevcut Açıyı Sabitle" butonuna basın.

4. İstasyonlar Arası Yumuşak Geçiş: İstasyon kartlarına tıklayarak kamera açısını yumuşak bir lerp animasyonuyla o açıya kilitleyebilirsiniz. "Serbest Kamera" butonuyla tekrar serbest gezintiye dönebilirsiniz.

5. Tek Dosya Standalone: Bu uygulama tek bir HTML dosyası olarak tasarlanmıştır. Harici derleyici veya yerel node sunucusu gerekmez.
